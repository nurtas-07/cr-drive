CR DRIVE — ГОТОВЫЙ САЙТ

ЗАПУСК НА КОМПЬЮТЕРЕ
Дважды нажмите START.cmd. Сайт откроется в браузере:
http://127.0.0.1:8787
Оставьте окно сервера открытым, пока смотрите сайт.
Для остановки нажмите Ctrl+C в этом окне.
Нужен Node.js (он уже установлен на этом компьютере).

ФАЙЛЫ
index.html, favicon.svg, assets/ — готовая сборка сайта.
source/ — полный исходный код React/Vite, тексты RU/KZ/EN и изображения.
serve.cjs, START.cmd — локальный запуск без установки дополнительных пакетов.

РЕДАКТИРОВАНИЕ
Откройте папку source. Выполните npm ci, затем npm run dev.
Для новой готовой сборки выполните npm run build.
Результат появится в source/dist.

ВАЖНО
Сайт сохранён только локально. Публикация не выполнялась.
Демо мониторинга использует демонстрационные данные.
Кнопки связи открывают существующие страницы CR Drive в Telegram и Instagram.
Устройство и дорожная фотография — концептуальные иллюстрации.

Основа: предоставленный вами питч CR Drive.
Подробности реализации: source/README.md.
